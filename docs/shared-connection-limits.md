# 共享连接配额

正式服务入口为已经完成密钥证明的 WSS 连接检查 PostgreSQL 共享配额。总量、当前用户、
手机设备和安装实例都必须有名额；Host 与手机合用总量/用户/安装配额，手机另受设备配额。
身份来自已验证的 ticket 或安装密钥，不接受客户端提供的用户、安装或源 IP 选择器。
同一 NAT 后的合法用户按各自身份计算，不使用低固定 IP 连接上限代替设备配额。

先应用迁移 `041_connection_limits`。默认值见
[`deploy/connection-limits.example.json`](../deploy/connection-limits.example.json)：总量 12000，
用户 256，设备 64，安装 128；每节点最多 256 条尚未完成握手的已升级连接。
这是初始资源保护设置，不证明系统已经通过这些数量的性能或故障验收。

## 配置与协商

可用 `REMOTE_CONNECTION_LIMITS_FILE` 提供仅当前所有者可读写的普通文件，例如 `0600`；
省略仍启用默认值。格式为示例中的六个必填整数，拒绝缺失、null、未知字段、大小写别名及
重复字段。总量为 1–20000，用户/设备/安装分别为 1–总量；pending_handshakes 为 1–4096。
所有节点须匹配同一数据库策略和规范化摘要，运行中的准入事务也核对它们，不能回退到无限
预算。可在不连接数据库时核对配置：

```sh
.local/remote connection-limits describe
.local/remote connection-limits describe --policy-file /受控目录/connection-limits.json
```

连接策略与命令速率策略独立；`command-limits replace` 只管理命令预算。连接策略变更使用[离线状态查询与比较替换](connection-policy-operations.md)，另需迁移 043。
先排空节点，再一致更新内容/摘要；不能删除策略或占用行来修改限制。策略缺失
而仍有设备占用或有效 Host 路由时，新节点不会自行补建。没有连接策略热重载接口。
初次上线也应排空尚不理解共享连接配额的旧节点。

## 握手与释放

握手前只有节点级 pending 预算，未证明密钥的请求不会占用某用户或设备的共享名额。
pending 满时拒绝本次升级后的握手，并通过原关闭路径终止传输；完成证明的活动连接不再
占 pending 预算。反向代理入口的 tunnel 预算仍独立，HTTP/TLS 公网入口的接入保护也继续
由部署负责，不能将本功能当作所有未认证连接的全局文件描述符上限。

手机先验证当前注册密钥并消费一次性 ticket，再用当前账号、设备 key version、成员关系、
安装、runtime、grant 版本/范围/期限申请名额。超额时在 hello.ok 前返回 `rate.limited` 并
关闭；该 ticket 已消费，重试应重新申请，不能复用它。失败后不进入业务路由。

手机占用绑定当前节点的 consumer generation、连接 UUID 和五分钟协议生命周期。正常关闭
按确切 node/generation/connection 释放，旧节点不能清理新节点的占用。节点租约结束、代次
改变或记录到期后占用不再有效，新准入每次最多清理 256 条失效行。记录保留三十秒时钟偏差
余量，只是容量元数据，不延长 socket 权限；关闭一般立即释放，无需等待该余量。

Host 不新增独立 socket 表，使用现有确定的 runtime/route/consumer 归属计算逻辑占用。
同 runtime 的已证明重连复用其逻辑名额，跟随新的 owner 和 epoch；不同 profile 分别计数。
配额检查与 Host 登记、路由、旧交互失效和审计在同一事务，拒绝会整体回滚，不替换原 Host。
主机凭据还在资源锁后及提交前按数据库当前时间复核，审计等待不能携带过期凭据完成登记。

容量查询使用固定共享策略行协调，并为 SERIALIZABLE 登记提供 MVCC 更新边界；确认中止
才执行既有有限重试。计数按不晚于事务快照的时间保守判断租约，避免锁等待期间看不见的
续租错误释放活动名额。资源数据更新不稳定或数据库故障会失败关闭。已过时或已结束的名额
可能被短暂保守计入；它们不会授予权限，也不承诺物理 socket 在每个瞬间等于逻辑占用数。

普通 Host 路由计数保留最长协议生命周期的保守近期活动窗口，以防部分失败的清理提前释放
仍可能存活的连接。单 runtime 归属、凭据期限、节点 generation、周期授权检查和撤权窗口
仍各自执行。占用表不保存正文、token、proof、网络地址或模型信息。

## 本地验证

小型 PostgreSQL 回归覆盖四种共享配额、独立节点及并发不超支、确切释放、Host/手机合计、
同 runtime 迁移复用名额、拒绝新 profile 不影响旧 Host、节点失效/代次变化、策略异常、
失效凭据与审计等待回滚、续租快照及空迁移往返。真实 WebSocket 另验证 pending 上限、
活动连接不占 pending、关闭后释放；正式双进程 TLS 夹具验证入口切换、owner 迁移和重新
握手后仍共享设备名额。正常本机 npm DSH `0.2.1-rc.2` 双节点链路单独回归。

身份与模型仍使用本地夹具；本次不涉及 Android APP、真机、大负载或厂商推送配置。
全局准入串行协调及新增查询的目标容量成本尚未测量，不能用功能用例宣称连接规模已验收。
