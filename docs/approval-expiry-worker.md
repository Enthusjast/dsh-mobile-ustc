# 审批过期的后台终结

正式入口的 `RunConsumer` 独立运行审批过期任务，不再依赖新的 Host 登记请求触发清理。
每秒尝试一批，默认最多终结 32 条；仓库接口允许 1–128 条，单次数据库操作最多一秒。
它与 consumer 续租、outbox 分发和连接授权检查分别运行，阻塞或失败不会取消其他任务。
停服务会取消并等待任务结束，不另开未受服务生命周期管理的后台进程。

先应用迁移 `044_approval_expiry`，为 metadata v1 的活跃审批增加部分索引。即使当前没有
启用审批签名配置，已存在的 v1 记录也继续清理；metadata v0 的历史记录不被重新解释。
新登记中原有的即时过期清理继续保留。

## 状态与事实

到期时间为请求和已接受决定期限中的较早者：

| 原状态 | 到期后 | 保留的执行事实 |
| --- | --- | --- |
| pending | expired | 未记录新决定或执行结果 |
| decision_received | outcome_unknown | 不能由服务端推断 Host 是否消费了允许决定 |
| allowed 且 host_state=consumed | outcome_unknown | 保留 consumed，不宣称工具未执行 |
| 已 settled、denied、cancelled、invalidated 或其他终态 | 原样 | 保留原签名、结果与历史 |

任务不调用原生挂起回调，不生成执行租约，也不恢复审批。签名决定、证据材料和指纹保持
原样。Host 后续报告的已验证执行事实仍可按既有状态机对账，包括在 unknown 后记录 settled。
手机现有审批订阅通过 `approval.ended` 重读当前权限下的状态，HTTP 状态查询也可读到终态。
Host 的本地超时、短期租约、最终 guard 与结果 outbox 继续独立执行。

## 并发与失败

每批先核对数据库恢复代次和本节点 consumer generation/租约，按最早到期顺序取得有过期
审批的 runtime 锁，再取得审批行锁。两层均用 `SKIP LOCKED` 跳过繁忙记录，保持与登记、
连接替换和 Host 结果写入一致的 runtime → approval 锁顺序。离线或已退役 runtime 的
过期记录也能被终结，不要求其重新连接。

处理状态和写审计期间不固定 consumer 行，允许本节点续租、outbox 轮询和 generation
替换继续进行。提交前再以兼容准入的共享锁固定当前 generation，使用新的数据库时间复核
租约；期间已换代、删除或到期的 consumer 不能提交本批变化。

多个节点可以同时运行；只有锁定相同审批并完成状态迁移的事务写入该次终结。状态、固定
白名单的成功审计与 `approval.ended` outbox 事件原子提交。审计/outbox 插入被忽略、写入
失败、提交失败或提交前 consumer 租约失效都会整体回滚；以后重试不会重复终结已提交行。
恢复隔离或错误代次不能执行清理。每个节点仍通过独立覆盖快照确认自己的 outbox 处理。

已有 `approval_state_transitions_total{cause="expiry"}` 只统计本进程确认提交的转换。
`control_available{worker="approval_expiry"}`、最后成功时间和执行耗时使用固定标签，失败
不清空其他 worker 的健康状态。成功空批次仅证明本次检查可用，不证明所有繁忙记录已处理。
处理时延受批次、积压、数据库可用性和锁竞争影响；权限检查及 Host guard 不依赖任务及时
运行来阻止过期执行。本轮没有宣称目标负载或生产过期通知时延已验收。

迁移 down 只移除索引，不删除审批、证据、审计或事件，也不恢复 pending。

## 验证

隔离 PostgreSQL 回归覆盖状态分类、较早决定期限、证据保留、批量上限、双节点竞争与逐
节点 outbox 覆盖、锁跳过、离线/退役记录、失败及提交回滚、恢复与代次隔离、取消，以及
等待审计期间 consumer 过期/换代后的回滚及续租/轮询仍可完成。索引迁移往返保留终态和
legacy 行。控制组件验证
清理阻塞时续租/分发/授权检查仍运行，失去 generation 则结束服务任务。

双生产进程 TLS 夹具在没有后续登记时自动终结预置 pending 元数据，并确认两个节点各自
覆盖事件及导出 worker 健康状态。正常签名审批链路另用本机 npm DSH `0.2.1-rc.2` 双节点
终端组合回归。身份和模型为本地夹具；未修改 Android APP，未运行真机、大负载或厂商配置。
