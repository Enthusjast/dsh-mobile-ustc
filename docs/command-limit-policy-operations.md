# 命令限流策略的离线变更

`remote command-limits` 提供本机管理员使用的配置工具，没有公网管理路由。它使用受控环境中
的数据库凭据；不能替代组织对管理员、配置来源和变更流程的核验。策略和摘要只包含公开的
预算数字，不包含用户、设备密钥、token 或正文。

`describe` 只读取本机期望配置，不连接数据库。`status` 和 `replace` 要求显式设置当前
`REMOTE_DATABASE_EPOCH` 和受控 `REMOTE_DATABASE_URL`，并要求数据库已解除恢复隔离。
恢复旧备份时仍应先完成[恢复隔离和当前身份重建](database-recovery.md)，不能用策略替换
恢复旧凭据或跳过授权检查。

## 查询与准备

先应用迁移 `039_command_rate_policy_changes`。在仓库根目录、使用按服务 README 构建的
二进制执行，数据库地址从受控环境注入，不写入命令行：

```sh
.local/remote command-limits status
.local/remote command-limits describe --policy-file /受控目录/new-command-limits.json
```

`status` 返回当前数据库代次、`configured`、策略 JSON/摘要、有效 consumer 租约数量和
`budgets_retained`。尚未配置时策略及摘要为 null；查询不会创建策略。它是只读一致快照，
不是“进程已经全部停止”的证明。暂停、断网或尚未登记的旧进程仍须由管理员独立核对；
所有维护 consumer 和 Relay/控制 worker 都应纳入排空范围。

新文件使用[既有共享命令预算格式](shared-command-limits.md)，为受保护普通文件，权限例如
`0600`。核对 `describe` 给出的新值和规范化摘要，以及 `status` 给出的当前摘要。窗口改变
会改变现有窗口的到期判定；收紧额度不会抹去已消费次数，可能暂时拒绝新命令。

## 替换与恢复服务

先停止并排空全部旧节点，再使用全新的操作 UUID 和刚核对的旧摘要：

```sh
.local/remote command-limits replace \
  --operation-id '<本次变更 UUID>' \
  --expected-sha256 '<status 返回的旧策略 SHA-256>' \
  --policy-file /受控目录/new-command-limits.json
```

事务内锁定当前恢复代次、consumer 登记/续租和策略行，重新核对旧摘要，并确认没有有效
consumer 租约。存在有效租约时拒绝，不自动停服务或删 consumer；进程崩溃后应等真实租约
到期，不手工缩短元数据。等待锁也有短期限，超时不放宽条件。

成功后原子更新当前策略、保存不可变变更回执和一条 `command_rate.policy.replace` 系统审计。
回执包含操作 UUID、数据库代次、前后摘要、规范化策略和数据库变更时间。审计只保存关联 ID
及摘要，不声称识别了操作者的学校身份。计数器、命令、grants 和执行结果不会被该事务重置。
SQL 未实际更新为期望策略、回执或审计写入失败时整体回滚。

随后让所有节点使用同一份新策略再启动。生产入口先登记 consumer 再核对策略，校验失败时
释放该 consumer 并在监听前退出。登记与替换互斥；运行中每次命令配额检查仍验证策略内容
及摘要，所以旧缓存不构成继续使用旧预算的许可。旧版本节点必须先排空，不能依赖新工具
强制约束尚不理解共享限流的程序。

## 输出丢失和并发

结果不明确或输出失败时，保留并重试原操作 UUID、原旧摘要和原文件内容，不创建新操作
掩盖未知结果。已提交操作的相同参数重试只返回原回执，服务已经重新上线时也能对账。
即使后来已应用其他策略，旧操作重试也不回退当前策略或再写审计。同一操作 ID 携带不同
参数、旧摘要竞争、相同策略的无效替换或错误数据库代次会拒绝。

新操作之间按 consumer 表和策略行串行，两个使用相同旧摘要的不同操作最多成功一个。
恢复隔离期间不允许变更；恢复后操作须使用当前新的外部代次和新的操作 UUID。

变更回执用于跨重启的去重及追溯，不能更新或删除。下行迁移遇到记录时拒绝，不删除回执来
回退。普通审计继续使用既有保留/归档机制；公开策略回执与资源运行计数分开保存。

## 验证

真实 PostgreSQL 测试覆盖计数保留、收紧限制、旧对象失败关闭、在线 consumer 拒绝、并发
比较替换、相同操作并发重试、历史重试不回退、新旧数据库代次、恢复隔离、实际更新/审计失败
回滚、记录不可变和迁移保护。CLI 用例模拟提交后输出失败，再由正式二进制带原参数对账。

双进程 TLS 服务用例验证在线拒绝、排空替换、旧配置启动失败并清理 consumer、新配置重新
可用，以及恢复在线后的原操作重试。正常本机 npm DSH `0.2.1-rc.2` 双节点链路另做回归。
这些是本地功能夹具证据；不涉及学校生产变更、Android APP、真机、大负载或厂商推送配置。
